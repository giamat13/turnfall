# Contributing

Thanks for your interest in Turnfall. To set up, follow [Build and test](README.md#build-and-test) in the README.

## Where things live

- `src/`: the page and the rules (`core.js`). Edit these.
- `data/`: the level data, generated by `tools/build.js`. Don't edit it by hand.
- `index.html`: generated by `npm run build` from `src/` and `data/`. Don't edit it by hand.
- `tests/`: the Playwright checks. The built page and the screenshots the tests save go to `build/`, which git ignores.

## Before you open a pull request

```sh
npm test
```

`npm test` rebuilds the page and runs every check. Commit the rebuilt `index.html` with your change.

If you change the rules in `src/core.js`, regenerate the levels with `node tools/build.js` and review the diff, since the levels depend on the rules.
