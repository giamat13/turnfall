# Contributing

Thanks for your interest in Turnfall. The Android app is the main product. The browser page is the base it was made from. The setup steps are in the [README](README.md).

## Where things live

- `app/`: the Android app. Its rules are in `app/src/main/java/io/github/giamat13/turnfall/game/`, and they must give the same answers as `src/core.js`.
- `src/`: the browser page, and the rules (`core.js`) that it runs. Edit these.
- `data/`: the level data, generated by `tools/build.js`. Don't edit it by hand. The Android build copies `data/levels.json`.
- `index.html`: generated by `npm run build` from `src/` and `data/`. Don't edit it by hand.
- `app/src/test/resources/fixtures/`: reference answers that `tools/make-android-fixtures.js` writes from `src/core.js`. Don't edit them by hand.
- `tests/`: the Playwright checks of the browser page. The built page and the screenshots the tests save go to `build/`, which git ignores.

## Before you open a pull request

```sh
npm test                           # the browser page: builds it, then runs all its checks
./gradlew :app:testDebugUnitTest   # the Android rules, against the reference answers
```

Commit the rebuilt `index.html` with your change.

If you change the rules in `src/core.js`, regenerate the levels with `node tools/build.js`, regenerate the fixtures with `node tools/make-android-fixtures.js`, port the change to the Kotlin rules in `app/src/main/java/io/github/giamat13/turnfall/game/`, and review the diffs. The levels depend on the rules.
